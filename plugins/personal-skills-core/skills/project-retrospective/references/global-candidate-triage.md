# Candidate principles
A proposed reusable rule should name a concrete failure, an applicable situation, the asset property
it protects and supporting evidence. Repeated independent occurrences are stronger evidence than one
episode. Compare existing guidance before proposing another rule; narrow rare cases to their owning
skill or project. Keep confidence and the condition that would invalidate the rule visible.
Deliver proposed snippets as part of the retrospective. They do not authorize edits to global rules,
AGENTS.md, permissions or memory. Apply only separately requested or already explicitly authorized
rule changes, using the platform's prescribed memory process when relevant.
