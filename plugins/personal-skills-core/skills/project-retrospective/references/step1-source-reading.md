# Evidence order
Locate the existing project record home. Read phase logs, decisions, glossary, linked details,
relevant lessons and git history before relying on conversation summaries. Search the named project
and known record locations, not every personal directory. Preserve a named consulted-source list.
If a record names an older location, verify it before declaring missing history. Do not create a
second home. Check old open items against current artifacts; annotate supersession when updating
records was requested. A compacted summary is a lead, not the full evidence trail. Declare missing
periods and avoid claims about user preferences without explicit evidence.
