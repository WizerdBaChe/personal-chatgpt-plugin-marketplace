> Scope of applicability: Formation of V-shaped grooves in silicon, glass, and related substrates for optical fiber positioning, fiber array units (FAU), and MEMS structures — covering the groove-cutting process itself (not alignment/bonding technology).

## 1. Theoretical Framework Anchoring

### Core first principles

| Scale / problem type | Foundational theory | Core physical quantity |
|------------|---------|-----------|
| Atomic / crystallographic | Dangling bond / back bond count per surface atom | Activation energy for atom removal, \(E_a\) |
| Crystal plane selectivity | Anisotropic wet-etch kinetics | Etch rate ratio (selectivity), \(R_{100}:R_{110}:R_{111}\) |
| Plasma etch (DRIE) | Time-multiplexed etch/passivation (Bosch process) | Scallop amplitude, sidewall taper angle |
| Laser ablation | Ultrafast laser-matter interaction, nonlinear absorption | Taper angle, heat-affected zone (HAZ) width |
| Mechanical dicing | Brittle fracture mechanics at blade-material interface | Chipping size (μm), edge quality |

### Inviolable physical constraints (the AI should warn the user here)

1. On (100)-oriented single-crystal silicon, anisotropic wet etchants (KOH, TMAH) will *always* terminate on {111} planes when etching along ⟨110⟩-aligned mask openings, producing a fixed sidewall angle of 54.74° relative to the wafer surface — this angle **cannot be tuned by process parameters**; only the etch depth, groove width, and surface roughness are adjustable. "The etching rate of single crystal Si in an anisotropic etchant varies with the crystallographic orientation of the substrate, which generally decreases in the order of (100) ≈ (110) > (111)"（單晶矽在非等向性蝕刻液中的蝕刻速率隨基板晶向變化，速率排序大致為 (100) ≈ (110) > (111)）[Chen2018].
2. Convex corners in KOH/TMAH anisotropic etching are geometrically unstable and *will* undercut unless explicitly compensated by corner-compensation structures in the mask layout — this is not an optional design consideration but a mandatory constraint for any V-groove array with crossing or terminating features [Pal2015].
3. DRIE (Bosch process) sidewalls are *inherently* scalloped due to the cyclic etch/passivation sequence; a perfectly smooth vertical sidewall from DRIE alone does not exist without post-processing (isotropic smoothing pulse or H₂ anneal) [DRIE_scallop_general].

> **Decision point (mandatory Tier 0 confirmation)**: when the user describes a V-groove fabrication need, the AI must confirm:
> "Is your goal (A) a crystallographically self-terminated {111} V-groove on single-crystal Si with fixed 54.74° sidewalls (requires KOH/TMAH wet etch, ⟨110⟩-aligned layout) / (B) an arbitrary-angle V-like trench with layout freedom, possibly on non-Si materials (requires DRIE, laser ablation, or dicing) / (C) a large-scale, low-precision groove for packaging/mechanical purposes where cost and throughput dominate over facet smoothness (mechanical dicing or grinding)?"
> The three goals correspond to entirely different process selection, mask/layout design rules, and achievable tolerance budgets.

## 3. Standard Modeling / Process-Selection Toolchain

```
Crystallographic / material-scale decision
→ Output: substrate type (single-crystal Si vs. glass/ceramic/polymer), required sidewall angle (fixed {111} vs. arbitrary)
    ↓
Process-selection scale
→ Input: substrate + angle requirement + layout constraints (⟨110⟩ alignment needed? convex corners present?)
→ Output: KOH/TMAH wet etch | DRIE/ICP-RIE | ultrafast laser ablation (+ optional wet-etch smoothing, i.e. FLICE/LIDE) | mechanical dicing/V-blade sawing | grinding-polishing
    ↓
Process-parameter scale
→ Input: chosen process + target etch rate / taper angle / roughness spec
→ Output: concentration-temperature recipe (KOH/TMAH) | RF power / cycle-time recipe (DRIE) | pulse energy / repetition rate / scan strategy (laser) | blade type / feed rate (dicing)
    ↓
Post-processing / quality-control scale
→ Output: corner compensation verification, roughness measurement (AFM/profilometer/LSM), chipping/undercut inspection, Telcordia GR-series qualification testing if for telecom deployment
```

| Pitfall | Trigger condition | How to recognize it | Correct approach | Source [Key] |
